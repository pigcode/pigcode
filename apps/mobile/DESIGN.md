# Pigcode 手机端视觉规范

方案 D「对话优先 + 桌面式菜单」是手机端的视觉基准。以下尺寸来自原型，Flutter 中使用逻辑像素。首页打开最近的会话，左侧菜单把会话页推到右边。iOS 和 Android 共用这套布局，系统控件按平台适配。[方案 D 的决定](https://github.com/pigcode/monorepo/issues/94#issuecomment-7064526109) · [原型源码](https://github.com/pigcode/pigcode/tree/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/apps/mobile-prototype)

## 主题和文字

- 使用桌面 Pigcode 默认浅色、深色的语义色，随手机系统切换。侧边菜单用 `--window`，会话页用 `--bg`，输入框、卡片和弹层用 `--surface`。主操作用 `--primary` 和 `--on-primary`，正文和次级信息沿用 `--fg`、`--fg-2`、`--muted`，分隔线用 `--divider`。
- 浅色的侧边菜单、会话底色和正文分别是 `#ededed`、`#fafafa` 和 `#202020`。深色分别是 `#151515`、`#1d1d1d` 和 `#f5f5f5`。状态色与 diff 增删色采用桌面相应 token。主表面用实色，分区使用细线，浮起的胶囊、卡片和弹层沿用原型的轻阴影。
- 界面使用平台系统字体。正文字号 15，行高倍率 1.45。普通文字用 400，标题、当前会话和主按钮用 500。输入框是 16/22，diff 正文是等宽 12/19。次级文字和行号按相应组件的尺寸与语义色处理。
- 共享颜色从 [`tokens.css`](../../packages/ui-primitives/src/styles/tokens.css) 生成 Dart 常量。构建时在浏览器中取 Pigcode 默认浅色和深色的计算值，复用现有 CSS 求色方式处理级联、`var()`、`oklch()` 和 `color-mix()`，输出保留透明度的 sRGB `Color(0xAARRGGBB)`。CI 重新生成并检查差异。手机的字号、间距和点按尺寸按本文件维护。[现有 CSS 求色代码](../../packages/ui-primitives/src/theme/resolve-color.ts)

## 会话页和菜单

| 组件         | 方案 D 的尺寸和呈现                                                                                                                                                        |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 会话顶栏     | 最小高 58，左右内边距 12，组件间距 10。左边是 44 的圆形菜单钮，图标 20。中间标题 16、字重 500，副行 12。右边是 44 高的胶囊，内含「改动」和「新会话」。                     |
| 会话时间线   | 组件与 [`packages/ui-chat`](../../packages/ui-chat/src) 的桌面时间线保持一致，只把外边距和触区适配到手机：用户气泡、工作折叠头、思考块、工具行及详情、摘要组、内联审批/提问卡、改动卡、操作栏。时间线外缘与每轮内容各留 16 的左右间距，用户消息之前留 56。回答用正文色，过程用次级文字。正常结束后把过程收成「用时 N 秒」的一行并保留最终回答；失败、被停止或没有最终回答时保持过程展开。 |
| 侧边菜单     | 宽为页面的 84%。打开时会话页右移同等宽度，左边两角圆角 34，并在左缘投下轻阴影。顶部是品牌名和搜索，随后是 50 高、圆角 16 的「新会话」。                                    |
| 会话和项目行 | 原型最小高 44，字号 15，圆角 12。会话行外侧各留 8、内侧各留 12，项目内嵌套行左侧为 40。当前会话用 `--active` 底色。                                                        |
| 菜单底部     | 电脑胶囊和设置圆钮高 50。电脑胶囊用状态点和文字表示连接状态，点开查看连接详情、切换或配对电脑。                                                                            |

侧边菜单依次显示「置顶」、项目分组和底部的电脑与设置。置顶会话只在置顶区出现。折叠项目和分组筛选使用原型的入口。长按会话显示置顶、标记已读或未读、归档等操作。

时间线把连续的思考、查阅、执行和修改合成摘要；摘要组的行、文件 chip、预览与展开规则沿用桌面 `summary-group.tsx`。正文和提问分隔相邻摘要组。工具行展开后显示命令、输出、内联 diff 或 MCP 结果，超长内容仍可打开底部弹层读取全文。执行中的工具优先显示命令说明。审批和提问以桌面同款卡片直接排在轮次末尾；输入区上方只保留一行等待提示。[桌面摘要组](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/packages/ui-chat/src/summary-groups.ts) · [桌面工具行](../../packages/ui-chat/src/tool-row.tsx)

会话行最多显示一个状态标记。出错用红色文字，其余按待处理、运行中、未读的顺序取一个。审批显示「等你确认」，提问显示「等你回答」，旧 Host 缺少请求类别时显示「等你处理」。在线时，普通会话的顶栏副行显示项目和 Agent 名称。连接异常时优先显示连接状态。离线列表显示缓存时间，隐藏会话状态标记。[方案 D 菜单与顶栏样式](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/apps/mobile-prototype/src/mobile.css#L1724-L2019) · [离线与缓存规则](https://github.com/pigcode/monorepo/issues/92#issuecomment-7072108758)

## 输入、待处理和改动

| 组件              | 方案 D 的尺寸和呈现                                                                                                                                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 输入框            | 卡片左右外边距 12，圆角 22，细描边和轻阴影。正文 16/22，发送和停止用 36 的圆形外观。                                                                                                           |
| 审批和提问        | 桌面同款卡片排在轮次内：圆角 12、1px 细边、16 内衬；审批按 decisions 显示「允许一次 / 本会话允许 / 拒绝」，计划审批用 Markdown 正文；提问支持单选、多选和其他。输入区上方只显示一行等待提示，提交仍走回执状态机。 |
| 运行中 loading 行 | 接在轮次末尾：3×3 点阵、「工作中」扫光、等宽计时；排队时写「排队中」不计时；计划进度并入这一行。 |
| 底部弹层          | 顶部圆角 22，默认最高 88%，顶部有 36×5 的握柄。标题字号 17、字重 500。弹层内容滚动，底部计入系统安全区。                                                                                       |
| 改动卡和全屏 diff | 每轮的改动卡列出文件及增删数。打开全屏 diff 后，顶部文件胶囊高 34、间距 8，文件之间可点击胶囊或横划切换。正文默认换行，保留换行开关。行号和增删标记列宽 38 和 14，增删行同时用符号和颜色区分。 |

运行中的 loading 行、内联审批和提问按 Host 状态切换。待发消息在输入区附近显示，保留撤回与「停止当前 run 并发送」操作。队列暂停时显示「继续发送」。改动数据绑定到所选 run，缺少 diff 时保留文件清单和不可用的说明。[桌面会话页](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/apps/mobile-prototype/src/variant-d.tsx#L150-L208) · [待发队列规则](https://github.com/pigcode/monorepo/issues/93#issuecomment-7073510830) · [按 run 查看改动](https://github.com/pigcode/monorepo/issues/91#issuecomment-7070294711)

全屏 diff 的路径固定在文件胶囊下方。统一补丁按实际行号显示，修改段之间用「⋯」分隔。离线列表在「新会话」下方显示最近的同步时间，离线会话在输入区上方显示缓存时间。[方案 D 全屏 diff 与文件切换](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/apps/mobile-prototype/src/common.tsx#L585-L649)

## 动效

- 侧边菜单推开或收回用 320 ms。内容页的圆角和阴影用相同过渡。底部弹层入场用 260 ms，遮罩淡入用 200 ms，关闭后把焦点还给打开它的控件。缓动为 `cubic-bezier(0.2, 0.7, 0.2, 1)`，与原型一致。
- 运行中显示 3×3 点阵和 loading 行计时，点阵每 175 ms 切换一帧。系统开启减少动态效果时，菜单和弹层直接切换状态，点阵停在第 3 帧并保留状态文字，扫光停止。[状态点动效](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/packages/ui-primitives/src/styles/indicators.css) · [菜单动效](https://github.com/pigcode/pigcode/blob/3910b67e261cdb0de8abbd475a8af862cbd2a0ec/apps/mobile-prototype/src/mobile.css#L1724-L1757)

## iOS 和 Android 适配

| 项目           | iOS                                                                                | Android                                                                                      |
| -------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 点按区域       | 至少 44×44 pt。                                                                    | 侧栏会话行和行内图标按钮按原型的 40/44/46 dp 排布，其他控件至少 48×48 dp。                  |
| 系统边缘       | 使用实际状态栏和底部 Home 指示区域。全屏 diff 及子页面保留系统返回手势和返回按钮。 | 使用实际状态栏、手势导航或三键导航的安全区。系统返回先收起当前弹层或会话菜单，再返回上一页。 |
| 键盘与文本选择 | 使用 Flutter 在 iOS 上的键盘、文本选择和编辑菜单行为。                             | 使用 Flutter 在 Android 上的键盘、文本选择和预测返回行为。                                   |
| 系统控件       | 权限提示由系统呈现，系统对话框使用 Cupertino 适配。                                | 权限提示由系统呈现，系统对话框使用 Material 适配。                                           |

图标大小和胶囊的视觉尺寸沿用原型，实际点击区域按上表处理。侧栏的行内图标按钮跟随所在行的 40/44/46 dp 高度，与行共用触区；标题栏右侧胶囊里的两个操作分别有独立的点击区，扩展后的区域互不重叠。空间不足时保留动作图标和读屏标签。侧栏会话行按方案 D 从 44 个逻辑像素起排布，带副标题的行随内容增高。正文、输入和按钮响应系统字体缩放，行和面板随内容增高，操作区保持可达。[Apple 按钮](https://developer.apple.com/design/human-interface-guidelines/buttons) · [Android 点按区域](https://developer.android.com/guide/topics/ui/accessibility/apps#touch-targets)

输入框、活动条和待处理面板随键盘上移，系统键盘遮挡范围与底部安全区各按实际值处理。中文输入法的候选与组词由系统输入控件处理。会话菜单和弹层打开后，读屏焦点进入当前区域，关闭时回到触发入口。连接状态与待处理状态同时提供可读文字。[Flutter 平台适配](https://docs.flutter.dev/ui/adaptive-responsive/platform-adaptations)

## 视觉验收

以方案 D 原型为参考，固定视口、像素倍率、主题和会话夹具，逐像素比对 Flutter 内容区。原型与 App 使用同一组系统安全区，只裁去系统栏。记录原型提交、渲染环境和差异像素数，差异计数为零才通过。覆盖浅色和深色的会话页、打开的菜单、新会话、审批和提问、全屏 diff 与离线列表。两端各检查点按区域、键盘弹出、系统返回、放大字号和减少动态效果。长会话上翻保持当前文字位置，回到底部后恢复跟随输出。[长时间线验证](https://github.com/pigcode/monorepo/issues/104#issuecomment-7065565709) · [手机端验收](https://github.com/pigcode/monorepo/issues/100#issuecomment-7075972281)
